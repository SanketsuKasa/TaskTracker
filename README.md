# Task Tracker

Веб-застосунок для керування задачами з календарем дедлайнів, реєстрацією через пошту та профілем користувача.

**Стек:** Node.js, Express, HTML, CSS, JavaScript (без фреймворків). Дані зберігаються в JSON-файлах.

## Можливості

- **Задачі:** створення, видалення, статуси Todo → In Progress → Done, категорії, пошук і фільтри.
- **Календар:** дедлайни по днях, перетягування задач між днями (drag & drop), список найближчих дедлайнів, підсвічування прострочених задач.
- **Експорт у `.ics`:** дедлайни можна відкрити в Google Calendar або Outlook.
- **Акаунти:** реєстрація та вхід через пошту, підтвердження пошти кодом із 6 цифр, відновлення пароля.
- **Профіль:** фото, зміна імені й пароля, статистика виконання.
- **Безпека:** паролі зберігаються лише у вигляді хешу (`crypto.scrypt` із сіллю), у кожного користувача свої задачі.

## Запуск

```bash
npm install
node server.js
```

Відкрийте http://localhost:3000 і зареєструйтеся.

Поки пошту не налаштовано, код підтвердження виводиться в терміналі, де запущено сервер.

## Надсилання листів (необов'язково)

1. Встановіть бібліотеку: `npm install nodemailer`
2. Скопіюйте `mail.config.example.json` у `mail.config.json` і вкажіть свою пошту та пароль застосунку.
   Для Gmail потрібна двоетапна перевірка, а пароль застосунку створюється на https://myaccount.google.com/apppasswords
3. Перезапустіть сервер.

> `mail.config.json` містить пароль і внесений до `.gitignore`. Не публікуйте його.

## Структура

```
server.js                  — сервер і API (задачі, акаунти, профіль)
mailer.js                  — надсилання листів із кодами
mail.config.example.json   — приклад налаштувань пошти
main.js                    — консольна версія меню
public/
  index.html               — головна сторінка
  login.html               — вхід, реєстрація, підтвердження пошти
  app.js                   — логіка інтерфейсу
  style.css                — стилі
```

Файли `users.json`, `sessions.json`, `tasks.json` і папка `uploads/` створюються автоматично під час роботи. У репозиторії вони лежать разом із `node_modules`, тож проєкт запускається одразу командою `node server.js`, навіть без `npm install`.
